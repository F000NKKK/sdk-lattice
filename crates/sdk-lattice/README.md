# sdk-lattice

High-level Rust SDK that composes net-lattice, tunnel-lattice, dns-lattice, and flow-lattice into one application-facing network programming interface.

## Status

Bootstrap stage: this crate is a placeholder. No public API has been
published yet.

The development workspace requires Rust 1.100 or newer.
